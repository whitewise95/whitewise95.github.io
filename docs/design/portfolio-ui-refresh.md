# 링크 경험 카드 추가

사용자 피드백에 따라 전체 UI 개편을 되돌리고, 기존 소개, 기술 목록과 회사별 경력 구성을 복원했다. 로컬 Pretendard 웹폰트와 기존 링크 스타일도 유지한다.

소개 아래, SKILL 위에 기존 블로그 링크가 있는 다섯 경험을 카드로 배치했다.

- 건강의신 개발과 출시 회고
- 청구의신 추가 개발
- 걸음수 집계와 랭킹 개선
- 실시간 채팅 시스템
- AdMob 리워드 광고 SSV

각 카드는 기존 블로그 목적지를 새 탭으로 연다. 회사별 상세 경력의 링크도 그대로 유지한다. 암호화 업무는 기존 상세 경력에 있으며, 연결된 블로그 글이 없어 카드에서는 제외했다.

카드 디자인은 사용자가 선택한 개편 시안의 형태를 유지한다. 데스크톱 3열, 태블릿 2열, 모바일 1열이다. 수정 원본은 `src/index.html`과 `src/assets/career.css`이며, `npm run build`로 생성 파일을 동기화한다.

브랜치: `feat/portfolio-ui-refresh`. 푸시하지 않는다.
