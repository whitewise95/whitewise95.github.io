About

차분하고 오래 쓰는 소프트웨어

화이트와이즈는 사용자가 일상 속 작은 과정을 더 쉽게 기록하고 반복할 수 있도록 돕는 소프트웨어를 만듭니다. 현재는 브루잉 과정을 안내하고 커피 기록을 쌓는 서비스인 브루웨이를 운영합니다.

이 홈페이지는 사업자 정보, 운영 서비스, 서비스 이용약관 및 개인정보 관련 문서를 안내하기 위한 정적 웹사이트입니다. 로그인, 결제, 개인정보 입력 기능은 제공하지 않습니다.

Business

소프트웨어 개발 및 운영

  • 서비스 기획과 개발

    사용자 흐름, 기록 구조, 앱 화면과 운영 정책을 함께 설계합니다.

  • 정적 문서 제공

    운영 서비스의 약관, 개인정보 처리방침, 수집·이용 동의문을 로그인 없이 열람할 수 있도록 제공합니다.

  • 서비스 운영

    브루웨이의 기능 개선, 정책 문서 관리, 문의 대응을 수행합니다.

  • 보안 관리

    사용자 정보, 인증서, API 키, 인증 토큰을 공개 저장소나 정적 사이트에 포함하지 않는 원칙을 둡니다.

Service

브루웨이(Brew Way)

브루웨이는 커피를 쉽게 체계적으로 내리고, 그날의 한 잔을 차곡차곡 기록하는 브루잉 가이드입니다. 앱인토스 appName은 brew-way입니다.

  • 브루잉 가이드: 추출 과정을 단계별로 확인
  • 원두 정보 등록: 사용하는 원두 정보를 정리
  • 타이머: 브루잉 과정의 시간을 확인
  • 기록: 그날의 커피 기록을 누적
